Official PushPushGo SDK client for Flutter apps (iOS, Android).

## Documentation

- **[Push Notifications](PUSH_NOTIFICATIONS.md)** - push notifications, subscriber management, beacons
- **[In-App Messages](IN_APP_MESSAGES.md)** - targeted in-app messages based on routes or custom triggers
- **[Live Activities](LIVE_ACTIVITIES.md)** - real-time Android 16 Live Updates and iOS Live Activities on the Lock Screen and in the Dynamic Island
- **[Deep links](DEEPLINKS.md)** - notification click URLs, custom URL schemes and Universal Links

## Credentials

The project ID can be found in the PushPushGo dashboard. An API key can be generated under *Project settings → Integration → Mobile*.
